## 1. Excel 列规范
- 读取第一个工作表（脚本可用 `--sheet` 指定），第一个非空行为表头，空行自动跳过。
- 页面顶部"下载模板"菜单（或脚本 `--dump-template 路径.xlsx [--sample org|person]`）可下载两种场景的示例模板：
  - 组织树 `org`：`部门 | 上级部门 | 组织负责人 | 职级 | 下级人数`
  - 汇报树 `person`：`姓名 | 主管 | 职级 | 部门 | 岗位 | 工号`
- 模板第 1 行为表头、第 2 行为各列填写说明（导入时会被当作普通行，建议删除后再填）、第 3 行起为 3 层示例。
- 每行一个节点，至少需要两列：**主字段**（节点名称，如"姓名"）与**上级字段**（如"主管"）。
- 上级为空，或为 `0`/`null`/`none`/`-`/`无` 等，表示顶层节点。
- 表头重名时，页面会把后出现的列改名为 `列名_2`、`列名_3`。
- 支持 `.xlsx`/`.xlsm`/`.csv`；页面内上传还支持 `.xls`（SheetJS 解析），烘焙脚本不支持 `.xls`。
- CSV 建议 UTF-8 编码；脚本会在失败时回退 GBK。

示例：

| 姓名 | 主管 | 职级 | 部门 | 工号 |
|------|------|------|------|------|
| 王总 |      | M6   | 总经办 | A001 |
| 李四 | 王总 | M5   | 研发中心 | A002 |
| 张三 | 李四 | P7   | 后端部 | A023 |

"张三的主管是李四"⇒ 李四是张三的上一节点。

## 2. 字段映射规则
| 映射项 | 必填 | 说明 |
|--------|------|------|
| primary 主字段 | 是 | 节点名称，始终显示，不可隐藏 |
| parent 上级字段 | 是 | 值指向上一节点的"标识" |
| id 节点标识列 | 否 | 上级字段的值在哪一列能找到；默认与主字段相同。上级填工号时设为"工号" |
| level 层级字段 | 否 | 参与搜索（如 职级 / 层级） |
| dept 部门字段 | 否 | 参与搜索 |

自动识别：页面按常见表头（姓名/名称/name、主管/上级/汇报对象/manager/parent、职级/层级、部门/团队）识别，并会在所有列中挑出"能命中最多上级值"的列作为标识列，所以上级填工号时通常也能自动识别。

异常处理（页面顶部黄色提示条会列出）：
- 上级值在标识列中找不到 → 该节点作为顶层节点。
- 多个顶层节点 → 统一挂到以"图表标题"命名的虚拟根（虚线框）。
- 循环引用（A→B→A）→ 在环的入口处断开，该节点提升为顶层。
- 标识重复（如两个"张伟"）→ 下级挂到第一个；建议改用工号作标识列。

## 3. 烘焙数据结构
`scripts/bake_data.py` 会把模板中唯一的 `/*__INJECT__*/ null` 替换为如下 JSON（`</` 已转义为 `<\/`）。手工构造时保持同样结构：

```json
{
  "aoa": [["姓名", "主管", "职级", "部门"], ["王总", "", "M6", "总经办"], ["李四", "王总", "M5", "研发中心"]],
  "fileName": "人员.xlsx",
  "title": "XX 公司组织架构",
  "fieldMap": { "primary": "姓名", "parent": "主管", "id": "", "level": "职级", "dept": "部门" },
  "displayConfig": {
    "visibleFields": ["职级", "部门"],
    "hiddenFields": ["手机"],
    "showLabels": false,
    "showLayoutToggle": true,
    "showButtons": true
  },
  "maxDepth": 2,
  "aggregates": [
    { "op": "count", "field": "", "scope": "desc", "label": "" },
    { "op": "sum", "field": "HC", "scope": "descSelf", "label": "团队HC" }
  ]
}
```
- `aoa` 必填：第 0 行表头，其余为数据行（全部为字符串）。
- `fieldMap` 中为空的项由页面自动识别补齐；补齐后主字段或上级字段仍缺失，页面会弹出字段设置。
- `displayConfig.visibleFields` 优先；否则用 `hiddenFields` 反选；两者都没有时默认显示层级、部门等前 3 个字段。
- `maxDepth`：`1`-`6` 或 `"all"`。
- `aggregates`：可选，聚合统计字段列表，空数组或缺省 = 不启用，见下节。

### 聚合统计字段（aggregates）
对每个节点的下级节点统计某个字段，结果以"显示名称 值"显示在卡片的普通字段之后（浅青底），并同步到 PPT。

| op | 名称 | 需要 field | 输出示例 |
|----|------|------|------|
| `count` | 下级人数 | 否 | `下级人数 12` |
| `nonEmpty` | 非空计数 | 是 | `手机非空数 18` |
| `sum` / `avg` | 求和 / 平均 | 是（数值） | `HC合计 120`、`年龄平均 31.4` |
| `max` / `min` | 最大 / 最小 | 是（数值） | `绩效最高 4.5` |
| `distinct` | 去重计数 | 是 | `部门种类数 4` |
| `dist` | 分布 | 是 | `职级分布 P5×6 P6×3 其他×2`（前 3 项，其余并入"其他"） |

| scope | 含义 |
|-------|------|
| `desc`（默认） | 所有下级节点（递归到底，不含自身） |
| `descSelf` | 所有下级节点 + 自身 |
| `direct` | 仅直接下级节点 |

规则：
- `label` 为空时自动命名：count 按范围为"下级人数 / 团队人数 / 直接下级数"，其余为"字段 + 后缀"（合计、平均、最高、最低、非空数、种类数、分布）。
- 数值解析会去掉千分位逗号、空格、`%`；空单元格与无法解析的单元格不计入。整数原样输出，小数最多 2 位，平均值 1 位。
- 范围内没有参与统计的节点（如叶子节点 + desc）时不显示该行。
- 统计基于完整树，不受展开层级、折叠、聚焦根影响；多根时的虚拟根显示全表汇总。
- 字段不存在的统计项会被忽略（重新导入另一份 Excel 时自动丢弃）。
- 页面"显示设置"里可临时关闭"显示聚合统计"，不会删除配置。

## 4. 行为细节
- 编辑模式：工具栏"编辑"进入。按住卡片拖动（指针式，移动超过约 5px 才算拖拽；轻点仍是展开/折叠）到另一张卡片上即变更上级，合法目标绿色、非法（自己/自己的子孙/原父级）红色高亮并被拒；拖到"设为顶层"投放区则清空上级。卡片 ＋ 新建下级、✎ 编辑信息（含"上级节点"下拉）、🗑 删除（有下级时可选"连同下级删除"或"下级上移"）。所有编辑改的是数据行，树/搜索/聚合/PPT 随之更新。
- 保存版本：工具栏"版本"→ "保存当前为版本"（默认名=标题+时间），存浏览器 `localStorage`（key `orgtree:versions`），刷新/重开不丢；可恢复（覆盖前确认）或删除。**打开页面时若本地已有版本，会自动加载最新的那个版本**，顶部显示「已加载最新版本 X」提示条，可点"恢复原始数据"回到本页烘焙/空数据。版本内容为节点数据（headers + rows + fieldMap + title），不含视图/显示设置。编辑为内存操作，需留存就存版本或"导出 Excel"。同源（同一发布域名或本地 file://）下各页面共享版本列表，列表按标题区分。
- 层级："展开 N 层"指根节点以下展开 N 层（根为第 0 层），与原 OrgChart 一致；超出的节点底部显示折叠条，单击局部展开一层，切换层级会清除局部展开。
- 布局：根节点下默认横向母线，第 2 层起默认纵向收纳框；纵向收纳框子节点 > 6 时分两列。
- 搜索：匹配主字段、层级字段、部门字段（包含匹配、不区分大小写），防抖 250ms；回车 / Shift+回车 在命中间切换。
- PPT：按当前可见树（当前根、展开层级、折叠、排序）生成单页 16:9；节点卡片内容 = 主字段 + 当前显示字段。根白底黑框，第 2 层灰底，第 3 层起在父卡下竖排并由左侧导轨连接（第 2 层下 > 6 个子节点分两列）。连接符为端到端吸附的 OOXML 连接符，在 PowerPoint/WPS 中拖动卡片会跟随。
- PNG：html2canvas 截取整个画布，最大边约 16000px。

## 5. 离线 / 内网使用
页面通过 jsdelivr（失败自动切 unpkg）加载：
- 启动必需：`react@18.3.1`、`react-dom@18.3.1`（UMD）、`@babel/standalone@7.24.7`
- 按需：`xlsx@0.18.5`（上传 Excel / 下载模板）、`html2canvas@1.4.1`（导出 PNG）

若用户环境无法访问这些 CDN：
1. 把上述文件下载到与 HTML 同目录（或内网静态服务器）。
2. 修改模板底部启动器中的 `BOOT` 与 `window.__LIBS__` 地址为本地路径，例如 `['./vendor/react.production.min.js']`。
3. 烘焙数据的页面不需要 `xlsx` 也能展示与导出 PPT。
